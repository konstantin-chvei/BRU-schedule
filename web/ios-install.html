Установка на iPhone и iPad

IPHONE · IPAD

Добавьте на экран «Домой»

Веб-версия открывается в Safari и устанавливается как приложение. App Store не нужен.

  1. Откройте «Расписание» в Safari. Если страница открылась внутри Telegram или другого приложения, выберите «Открыть в Safari».
  2. Нажмите «Поделиться» — квадрат со стрелкой вверх в панели Safari.
  3. Прокрутите меню вверх и выберите «На экран Домой». Если пункта не видно, откройте «Изменить действия» и добавьте его.
  4. При желании включите «Открывать как веб-приложение», затем нажмите «Добавить».
  5. Запустите приложение с нового значка. Подключитесь к интернету и добавьте профиль. Индекс и расписание загрузятся только после соответствующего действия.

Офлайн-режим

Интерфейс, расписание, дедлайны и настройки сохраняются на устройстве. Новые данные из GitHub загружаются только по нажатию.

Для установки нужен сайт GitHub Pages по HTTPS. Предпросмотр Arena и локальный файл не подходят.
