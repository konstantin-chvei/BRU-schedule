Добавьте на экран «Домой»

Веб-версия открывается в Safari и устанавливается как приложение. App Store не нужен.

  1. Откройте страницу расписания в Safari: перейти к приложению. Если ссылка открылась внутри Telegram или другого приложения, выберите «Открыть в Safari».
  2. Нажмите кнопку «Поделиться» — квадрат со стрелкой вверх в панели Safari.
  3. Прокрутите меню вверх и выберите «На экран Домой». Если пункта не видно, нажмите «Изменить действия» и добавьте его.
  4. При желании включите «Открывать как веб-приложение», затем нажмите «Добавить».
  5. Запускайте «Расписание» с нового значка. При первом запуске подключитесь к интернету и выполните поиск: по нажатию кнопки устанавливается кэш интерфейса и сохраняются загруженные данные.

После публикации файлов в GitHub следующий поиск проверяет индекс, а открытие профиля загружает его расписание. Веб-версия не запрашивает сайты университетов.

Для установки нужен HTTPS-сайт GitHub Pages. Вкладка GitHub Preview или локальный файл не подходит.
