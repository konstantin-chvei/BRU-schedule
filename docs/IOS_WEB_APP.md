# iOS-версия через GitHub Pages

Для iPhone и iPad доступна самостоятельная веб-версия/PWA в `web/`, визуально и по основным сценариям повторяющая Android: нижняя навигация, календарь недели/семестра, занятия, задачи и настройки. Она устанавливается из Safari на экран «Домой», читает только статические GitHub-индексы и подготовленные файлы расписаний; отдельная нативная сборка iOS для установки не требуется.

Режимы интерфейса, профили, сохранённые расписания, пользовательские пары и заметки, дедлайны и напоминания хранятся локально в браузере. Service worker кэширует оболочку и файлы, уже запрошенные пользователем. При запуске PWA каталоги не опрашиваются: запросы выполняются после нажатия «Найти», «Обновить расписание» или проверки сообщения дня. Факультетские расписания не загружаются напрямую с сайтов вузов.

## Публикация

Workflow `.github/workflows/deploy-pages.yml` собирает `web/`, `schedule-data/` и ежедневные тексты, затем публикует их через GitHub Pages. Он реагирует на изменения ветки `arena/a130e7c0-bru-schedule` и `master`.

1. В настройках репозитория откройте **Pages**.
2. Для **Build and deployment** выберите **GitHub Actions**.
3. Убедитесь, что Actions разрешено публиковать Pages, затем запустите workflow `Deploy iOS web app to GitHub Pages` вручную или отправьте обновление данных.
4. После успешного deploy адрес сайта будет `https://konstantin-chvei.github.io/BRU-schedule/`.

Репозиторий сейчас private, поэтому доступность Pages зависит от настроек и тарифа GitHub. Для общей установки пользователями веб-сайт и файлы расписаний должны быть доступны браузеру по HTTPS без авторизации. Не вставляйте токен GitHub в `web/`, Android или iOS-клиент.

## Инструкция для пользователей iPhone/iPad

1. Откройте `https://konstantin-chvei.github.io/BRU-schedule/` в **Safari**. Если ссылка открылась во встроенном браузере Telegram, выберите «Открыть в Safari».
2. Нажмите **Поделиться** — квадрат со стрелкой вверх.
3. Выберите **На экран Домой**. Если пункта нет, откройте «Изменить действия» и включите его.
4. Включите **Открывать как веб-приложение** (если пункт доступен) и нажмите **Добавить**.
5. Откройте «Расписание» с появившегося значка. При первом запуске подключитесь к интернету и выполните поиск — после явного нажатия приложение установит service worker и начнёт кэшировать интерфейс, индексы и открытые файлы расписания.

Инструкция также находится на опубликованной странице `/ios-install.html` и открывается из самой веб-версии.
