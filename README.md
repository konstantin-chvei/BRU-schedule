# Расписание

Кроссплатформенное расписание для студентов вузов Беларуси на Kotlin Multiplatform и Compose Multiplatform. Вуз выбирается на главном экране: для Белорусско-Российского университета доступен каталог групп и преподавателей; для БГУ в первой очереди подключены HTML-таблицы Мехмата и открытые Google Sheets Экономического факультета и ФПМИ. Другие вузы можно добавить по прямой HTTPS-ссылке на распознаваемую HTML-таблицу. PDF/Excel/DOC, JavaScript-календари и сайты с авторизацией требуют отдельных мобильных адаптеров; backend не используется. Архитектура находится в модуле `shared`: Clean Architecture + MVVM, SQLDelight Offline-First база с V−1 snapshot/rollback, KMP Settings для настроек, Ktor для загрузки страниц и общий Compose UI для Android/iOS.

## Основные возможности

- Выбор вуза на главном экране и добавление пользовательских вузов; выбранный вуз и его расписания сохраняются отдельно.
- Несколько профилей одновременно: группы и преподаватели из каталога БРУ, группы БГУ из HTML-таблиц/Google Sheets или профили по прямым ссылкам на HTML-таблицы других вузов.
- Быстрое чтение из локального кэша; ручные правки и пары защищены от перезаписи сайтом.
- Обновление расписания с сохранением предыдущей версии и явным откатом.
- Парсинг двухнедельных таблиц группы и страниц занятости преподавателей; распознанный цикл «Неделя 1 / Неделя 2» разворачивается от текущей даты до конца сессии и ещё на 7 дней. Для белорусского и российского отделений границы заданы отдельно, для ИФЗО дату окончания можно указать вручную.
- Видимые состояния первичной загрузки, обновления, ошибки и сохранённого офлайн-кэша.
- Выбор синей, чёрной или белой темы и настройка цветовых акцентов лекций, лабораторных, практик и прочих занятий; параметры сохраняются в KMP Settings.
- Ежедневная фраза загружается при запуске из [`content/daily-messages.txt`](content/daily-messages.txt) через GitHub Contents API и кэшируется локально для работы без сети.
- Минималистичный Compose UI с плавной навигацией для Android и iOS.
- Дедлайны, связанные с парами, бейджи количества незакрытых задач и общий хронологический список.

## Запуск

```bash
bash ./gradlew :androidApp:assembleDebug
bash ./gradlew :shared:allTests
```

Откройте `iosApp/iosApp.xcodeproj` в Xcode для iOS. Требуются установленный JDK и Android SDK; iOS-сборка требует Xcode. В Android добавлено разрешение `INTERNET`; без сети кэш всё равно доступен.
