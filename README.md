# Расписание

Мобильное приложение для расписания занятий и дедлайнов. Android и нативная iOS-оболочка используют Kotlin Multiplatform и Compose Multiplatform; для iPhone и iPad доступна устанавливаемая PWA.

## Возможности

- Каталоги поддерживаемых групп и преподавателей, раздельные для каждого вуза.
- Локальное хранение и офлайн-доступ; обновление расписания — по запросу, с сохранением личных пар и обнаружением конфликтов.
- Неделя и семестр до окончания сессии плюс неделя; даты можно настроить отдельно для вуза и расписания.
- Ручные пары, заметки, повторы и дедлайны, связанные с предметом, парой или без привязки; общие и индивидуальные напоминания.
- Темы, настраиваемые акценты и масштаб текста 100–150% с предпросмотром.
- Ежедневные сообщения из `content/daily-messages.txt`, которые можно обновить без выпуска приложения.
- PWA повторяет основные экраны Compose, хранит данные на устройстве и работает офлайн после первой загрузки.

Клиенты не используют backend, не обходят и не опрашивают сайты вузов. Сетевые запросы выполняются только после явного действия пользователя; файлы расписаний и каталоги подготавливаются отдельно инструментами в `tools/schedules/`.

## Сборка и установка

Требуются JDK 21 и Android SDK Platform 37.

```bash
./gradlew :shared:allTests
./gradlew :androidApp:assembleDebug
```

Релизная сборка и подпись описаны в [`docs/BUILD_AND_DISTRIBUTE.md`](docs/BUILD_AND_DISTRIBUTE.md). Установка PWA на iPhone/iPad — в [`docs/IOS_WEB_APP.md`](docs/IOS_WEB_APP.md).
