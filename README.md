# universityschedule

universityschedule помогает смотреть расписание занятий и держать под рукой важные учебные дела. Выберите группу или преподавателя, добавьте личные пары и заметки. После загрузки расписание можно открыть без интернета.

## Установка на iPhone и iPad через Safari

1. Откройте [universityschedule](https://konstantin-chvei.github.io/BRU-schedule/) в Safari. Если ссылка открылась во встроенном браузере Telegram или другого приложения, выберите **«Открыть в Safari»**.
2. Нажмите **«Поделиться»** — квадрат со стрелкой вверх.
3. В меню выберите **«На экран Домой»**. Если этого пункта нет, прокрутите список или добавьте его через **«Изменить действия»**.
4. Если появится настройка **«Открывать как веб-приложение»**, включите её и нажмите **«Добавить»**.
5. Запустите universityschedule с нового значка на домашнем экране. Для первой загрузки расписания понадобится интернет; после этого сохранённое расписание будет доступно без сети.
