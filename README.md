# Расписание

Кроссплатформенное расписание для студентов вузов Беларуси на Kotlin Multiplatform и Compose Multiplatform. Приложение и iOS-веб-версия ищут группы и преподавателей в статических GitHub-каталогах, а при обновлении загружают опубликованный файл расписания с GitHub Pages. Клиенты больше не обходят страницы вузов: подготовка снимков и обновление каталогов вынесены в Python-скрипты `tools/schedules/`. Списки групп и преподавателей хранятся отдельно для каждого вуза; новые университеты добавляются через реестр и структуру данных. Архитектура Android остаётся в модуле `shared`: Clean Architecture + MVVM, SQLDelight Offline-First база с V−1 snapshot/rollback, KMP Settings для настроек и общий Compose UI. iOS доступен как устанавливаемая веб-страница GitHub Pages с офлайн-кэшем.

## Основные возможности

- Выбор вуза на главном экране; данные каждого университета изолированы в отдельной папке `schedule-data/universities/<id>/`.
- Добавление расписания только по поиску группы или имени преподавателя. Ввод ссылки на источник удалён; список профилей читается из отдельных GitHub-индексов групп и преподавателей.
- Быстрое чтение из локального кэша; ручные пары и правки сохраняются при обновлении файла из GitHub.
- Обновление расписания с сохранением предыдущей версии и явным откатом.
- Парсинг двухнедельных таблиц группы и страниц занятости преподавателей; распознанный цикл «Неделя 1 / Неделя 2» разворачивается от текущей даты до конца сессии и ещё на 7 дней. Для белорусского и российского отделений границы заданы отдельно; дату окончания можно переопределить для конкретного расписания, если факультет завершает сессию в другой день.
- Видимые состояния первичной загрузки, обновления, ошибки и сохранённого офлайн-кэша.
- Выбор синей, чёрной или белой темы и настройка цветовых акцентов лекций, лабораторных, практик и прочих занятий; параметры сохраняются в KMP Settings.
- Ежедневные фразы обновляются из GitHub Pages вручную в настройках (проверка не чаще раза в сутки); последняя версия хранится локально.
- Минималистичный Compose UI для Android и отдельная iOS PWA в `web/`, устанавливаемая из Safari на экран «Домой».
- Веб-приложение кэширует оболочку, индексы и открытые расписания на устройстве для работы без сети.
- Python-инструменты для обнаружения профилей по сохранённым страницам, обновления снимков и генерации университетских папок: [`docs/SCHEDULE_DATA.md`](docs/SCHEDULE_DATA.md).
- Дедлайны, связанные с парами, бейджи количества незакрытых задач и общий хронологический список.

## Запуск

```bash
bash ./gradlew :androidApp:assembleDebug
bash ./gradlew :shared:allTests
```

Для iPhone/iPad откройте GitHub Pages и выберите в Safari «Поделиться» → «На экран Домой». Пошаговая инструкция: [`docs/IOS_WEB_APP.md`](docs/IOS_WEB_APP.md). Проект нативной iOS-сборки остаётся в репозитории для проверки общего кода, но пользовательская версия для iPhone/iPad распространяется как веб-приложение. Для Android-сборки требуются JDK и Android SDK; без сети локально сохранённые расписания доступны.
